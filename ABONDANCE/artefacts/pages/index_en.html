Reproduce the calculation

# from the repository root
py -3 ABONDANCE/electricite_abondance.py     # 21 equations, 21 checks
py -3 ABONDANCE/eau_abondance.py            # 15 equations, 15 checks
py -3 ABONDANCE/agriculture_abondance.py    # 18 equations, 18 checks
py -3 ABONDANCE/generer_abondance.py        # rebuilds pages, figures, JSON, CSV, Markdown
# off Windows: replace py -3 with python3

A computed document, not a hand-written one: re-run the module and the page reappears.
